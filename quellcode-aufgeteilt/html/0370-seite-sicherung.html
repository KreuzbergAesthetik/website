Sicherung
Die Sicherung ist eine ZIP-Datei mit allen Daten, Fotos und Dokumenten. Sie wird immer mit einem eigenen Passwort verschlüsselt. Sie ist unabhängig vom Geräte-Abgleich: Wird dort versehentlich etwas gelöscht, bleibt sie erhalten.
Sichern speichert den aktuellen Stand. Laden liest eine Sicherung wieder ein, bei mehreren Teilen bitte alle Teile gemeinsam wählen. Einzelne Formulare, Rechnungen oder Patienten liest der Knopf Import unter der Patientenliste ein.
