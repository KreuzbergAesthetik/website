Webformulare
Patienten füllen die Formulare am Handy aus und unterschreiben mit dem Finger. Daraus entsteht ein PDF. Schicke ihnen den Link, zum Beispiel über eine Nachrichtenvorlage mit den Platzhaltern {LinkAnmeldung}, {LinkAnamnese} und {LinkErinnerung}.
So kommen ausgefüllte Formulare in die App

1. Mit eingerichtetem Geräte-Abgleich (Praxis, Geräte-Abgleich) landen die Formulare verschlüsselt im Postfach. Du bekommst nur eine kurze E-Mail ohne Patientendaten, die App zeigt „Abrufen (n)“ unter Patienten und oben eine Leiste. Ein Tipp übernimmt alles.

2. Ohne Abgleich kommt das PDF wie bisher per E-Mail: Anhang speichern und unter Patienten den Knopf Import wählen.

3. Die Anmeldung legt den Patienten an oder ergänzt ihn. Die Terminerinnerung trägt E-Mail und Einwilligung ein.

Anamnese ohne Namen: Der Bogen läuft nur über einen persönlichen Code (Link mit ?c=Code). Der Link mit dem richtigen Code wird in Nachrichten mit dem Platzhalter {LinkAnamnese} automatisch für den jeweiligen Patienten eingesetzt (oder über die Schaltfläche „Anamnese senden“ in der Akte). Schicke ihn erst, wenn die Anmeldung da ist. Beim Import ordnet die App die Anamnese über den Code zu (bei einem neuen Code legt sie auf Wunsch einen neuen Patienten an oder ordnet den Code einem vorhandenen zu), füllt Allergien, Medikation und Diagnosen und hängt das PDF an die Akte. Die Unterschrift kommt vor Ort auf das PDF.
