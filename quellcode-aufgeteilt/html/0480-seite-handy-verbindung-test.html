Handy-Verbindung (Test)
Prüft, ob sich Handy und Tablet direkt im WLAN verbinden können, ohne Server und ohne Internet. Dazu zeigt das Tablet einen QR-Code, das Handy scannt ihn und zeigt einen Antwort-Code, den das Tablet scannt. Gesendet werden nur zufällige Prüfdaten, keine Patientendaten. Beide Geräte müssen im selben WLAN sein (kein Gäste-WLAN).
